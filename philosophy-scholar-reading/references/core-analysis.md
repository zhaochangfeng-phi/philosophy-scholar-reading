# 核心分析规范

## 论证账本

每个 A 编号记录：位置与提出者、目标结论及力度、显式前提 P、隐含前提 H、推理连接 I、中间结论、方法、关系、评价和可修复性。重复出现的同一论证保留编号并登记所有位置。

每个 U 编号记录：位置、提出者、内容、功能、支撑状态及相关 A 编号。U 项包括没有给出理由的主张、定义、区别、范围限定和异议；推理强度标为“不适用／未展开”。

## 六维评价

| 维度 | 必须回答的问题 |
|---|---|
| 可靠性 | 引文和重构是否可信？前提获得何种理由？哪些事实可核查，哪些解释仍不确定？ |
| 论证强度 | 演绎结构是否有效；归纳、溯因、类比或诠释性推理提供多强支持？是否存在替代解释？ |
| 合理性 | 概念是否稳定、结论是否过度、举证责任是否满足、目标读者能否接受前提？规范推理是否补出事实到规范的桥梁？ |
| 背后支撑 | 支撑来自定义、逻辑规则、概念关系、直觉、思想实验、经验事实、解释力、规范原则、证言还是理论承诺？原文是否实际提供？ |
| 缺陷 | 已能证明的形式错误、偷换概念、循环支持、缺失关键前提、量词或模态跳跃、不相关依据是什么？具体损害哪一步？ |
| 潜在问题 | 尚未坐实的脆弱点、反例、边界条件、翻译歧义或竞争解释是什么？什么信息可以消除疑问？ |

评价前提时另标注其类型、支撑来源和承重程度。可用“稳固／可争议／脆弱”帮助阅读，但评级必须附理由，不能代替六维分析。

演绎有效而前提可争议时写“形式有效，健全性取决于 P2”。非演绎论证按相关性、充分性、代表性、替代解释和结论力度评价。推理无效时给出反模型或指出失效规则；想象案例必须满足所有前提才构成反例。

## 关系模型

关系表字段：E 编号｜来源集合｜目标｜关系类型｜联合或各自独立｜作用对象｜文本位置与理由｜作者明示或分析者重构｜确定程度｜评价状态。

关系类型：

- **单独支撑**：某论证结论支持另一前提或结论。
- **联合支撑**：若干理由必须共同工作；用 AND 节点表示。
- **独立汇聚支撑**：多条理由分别提供支持；不能因目标相同就视为联合。
- **反驳结论**：支持与目标结论不相容的主张。
- **攻击前提**：削弱具体 P 或 H。
- **攻击推理**：承认前提也不足以按该 I 支持结论。
- **联合／独立攻击**：按是否必须合用区分。
- **串联**：一项结论成为另一项前提。
- **并列／互补**：讨论同一问题但没有支持或冲突关系。
- **限定／例外**：收窄结论适用范围。
- **回应／修复**：针对攻击或缺陷；成功回应只恢复相应路径。
- **张力／不相容**：在特定解释下难以同时成立；没有理由时不冒充攻击论证。

图示须用账本编号，箭头标记“支撑”“攻击前提”“攻击推理”等。先完成关系表，再按可读性拆分总图和局部图；孤立论证也保留。

## 方法识别及检验

- **演绎**：检查形式、量词、范围、模态及隐含前提。
- **归纳**：检查样本、代表性、选择偏差、反例和结论范围。
- **溯因／最佳解释推论**：比较替代解释的范围、代价和独立支持。
- **类比**：说明相似维度为何与结论相关，并检查关键差异。
- **先天证成**：指证成不依赖特定经验调查；不要与先验论证混同。
- **先验论证**：由被承认的 X 推到使 X 可能的必要条件 Y；检查 X→Y 是否必要及是否从认识条件跳到世界结构。
- **归谬**：定位假设和矛盾，说明应撤回哪项；不可接受后果不必然是形式矛盾。
- **滑坡**：区分因果、制度先例和概念型，逐环节检查机制、阈值、阻断点与规范前提。
- **反例／思想实验**：核对量词、条件、可能性种类和案例是否预设答案。
- **概念分析／定义**：检查必要充分条件、规定性定义和日常／技术含义切换。
- **两难／分情况**：检查分支是否穷尽及每一支是否成立。
- **模态／可设想性**：区分认识可能、逻辑可能、形而上可能和物理可能。
- **回溯／无穷倒退**：解释为何倒退恶性，并比较终点、循环或整体解释。
- **实践／规范推理**：标明价值前提、行动者、替代选择和权衡。
- **内在批判／辩证法**：用对象自身承诺揭示矛盾或张力，并区分二者。
- **反思平衡**：检查原则、判断与背景理论的调整是否受独立约束。
- **现象学／诠释／谱系**：先说明其描述、解释或历史揭示功能，再评价其中实际出现的推理。
- **权威／证言**：检查专长、争议、归属证据和独立理由。

方法可以嵌套。记录文本线索、局部结构、确定度和替代分类，不凭关键词命名。
