# Philosophy Scholar Reading

一个面向 Codex 的哲学文献精读与论证分析技能。它把文本理解、论证重构、批判评价、论证关系、方法识别和研究迁移整合到同一套可追溯流程中。

## 用途

这个技能适合：

- 精读哲学论文、原著、章节或哲学草稿；
- 总结核心观点，并将观点链接到具体论证和原文位置；
- 重构主论证、次级论证、对手论证、反驳与回应；
- 逐项评价论证的可靠性、强度、合理性、背后支撑、缺陷和潜在问题；
- 梳理联合支撑、独立支撑、攻击结论、攻击前提、攻击推理、回应、串联和并列关系；
- 识别演绎、归纳、溯因、类比、先验论证、归谬、滑坡、思想实验、模态论证、现象学、诠释学和谱系方法；
- 对英文分析哲学文本进行可选的中英双语重构和适度形式化；
- 分析经典文献的选题、研究方法、写作结构、学术位置及其对个人研究的启发；
- 持续阅读长篇著作，并维护统一的论证编号、术语表和覆盖记录。

它不适合单独的公式逻辑练习或数学证明；这些任务应使用专门的逻辑或证明技能。

## 主要特点

1. **完整覆盖**：为每个论证分配稳定的 `A` 编号，为没有展开理由的主张、定义或限定分配 `U` 编号，防止漏掉不显眼的推理。
2. **六维评价**：分别检查可靠性、论证强度、合理性、背后支撑、已确认缺陷和潜在问题。
3. **精确的论证关系**：区分联合与独立的支撑或攻击，并允许攻击具体前提或推理连接。
4. **多传统适配**：不会把形式化分析强加给现象学、诠释学、谱系学或文学性哲学文本。
5. **可选双语模式**：关键前提、结论和术语可以保留中英对照；分析者评价默认保持简洁。
6. **研究训练模式**：按需分析选题策略、方法、写作和学术影响，但不会在缺少资料时编造经典地位或文献脉络。
7. **克制的自动化**：不会自动建立研究画像、修改阅读清单或创建重读提醒。

## 安装

把仓库中的 `philosophy-scholar-reading` 文件夹复制到：

```text
~/.codex/skills/philosophy-scholar-reading
```

重新载入 Codex 技能列表后即可使用。

## 使用示例

```text
请用 $philosophy-scholar-reading 精读这篇哲学论文，总结核心观点，重构并评价全部论证，最后绘制论证关系图。
```

```text
请开启双语分析哲学模式，保留关键前提和结论的英文，并检查形式化过程中是否改变了原文含义。
```

```text
请分析这篇经典文献的选题、论证结构和写作方法，并说明哪些方法可以迁移到我的研究中。
```

## 分析模式

- **综合精读**：核心观点、完整论证账本、六维评价、关系图和方法识别。
- **双语分析哲学**：中英对照、半形式化、前提承重和反驳—回应。
- **经典与研究迁移**：选题、研究方法、写作、学术位置和可执行的研究启发。
- **完整学者模式**：组合上述模式，适合长篇或系统性研究。

技能结构、YAML 元数据和内部引用路径已经检查。独立前向测试覆盖了主论证、联合支撑、独立支撑、针对推理连接的攻击、作者回应和未展开主张。测试未发现阻塞问题，但这不代表所有哲学传统、文件格式或文本质量都已经穷尽测试。

## English summary

`philosophy-scholar-reading` is a Codex skill for close reading and argument analysis of philosophical texts. It reconstructs and evaluates arguments, maps support and attack relations, identifies philosophical methods, optionally provides bilingual analysis of English texts, and extracts research and writing lessons from classic works.
